# Changelog

All notable changes to this project will be documented here.

The format is inspired by Keep a Changelog and the project uses semantic versioning for public releases.

## [1.0.0] - 2026-09-24

### Added

- Project-first interactive session selection.
- Persistent opt-in session list across multiple projects.
- Managed Codex App Helper detection.
- Interactive daemon-only helper installation prompt.
- Managed app-server daemon startup and remote-control enablement.
- Local Swift WebSocket/JSON-RPC helper for the Codex control socket.
- Usage-limit-aware automatic resume for explicitly selected sessions.
- launchd background scheduling.
- Status, logs, restart, daemon lifecycle, and uninstall commands.
- Fail-closed rate-limit behavior.
- English-only public repository documentation and CLI text.
